## Standard Data Schema
Every record in these registries contains the following normalized columns:
* `license_number`: Official TDLR state license identifier
* `license_type`: Specific trade license category / qualification tier
* `license_subtype`: Endorsement details (e.g., Class A unlimited vs. Class B systems, Incident Management vs. Consent Tow)
* `business_name`: Primary operating entity name or registered DBA
* `owner_name` / `operator_name`: Master licensee / qualifier on record
* `business_address`: Physical operational or dispatch street address
* `business_city_state_zip`: Municipality, state, and postal code
* `business_county`: Texas county of legal jurisdiction
* `business_telephone`: Contact phone number registered with the state board
* `license_expiration_date`: Official regulatory expiration date
